# Almaty Device — сайт магазина

Промо-страница магазина игровой периферии к релизу GTA VI.
Один файл `index.html`, без сборки и зависимостей.

## Что поменять перед запуском на реальный домен

Всё редактируется в начале блока `<script>` в `index.html`:

- `PRODUCTS` — товары, бренды и цены (сейчас там примеры);
- `PROMO` — промокод, размер скидки и срок действия;
- `SETUP` — четыре товара в блоке «Сетап к релизу»;
- `RELEASE` — дата обратного отсчёта;
- `WA` — номер WhatsApp, куда уходят заказы.

Строку «Товары, цены и размер скидки на странице — примеры» в каталоге удалите после замены товаров.
